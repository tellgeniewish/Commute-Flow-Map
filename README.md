# 🧭 통근·통학 이동 흐름 지도

**🚉 사람들은 어디에서 어디로 통근·통학할까?**

2020년 KOSIS 인구총조사 통계를 활용하여 전국 17개 시·도의 통근·통학 이동 특성을 8개 권역으로 구분해 살펴보는 인터랙티브 지도입니다. 거주지와 통근·통학지 사이의 이동 방향과 규모를 시각화하고, 권역별 주요 이동 경로, 유입·유출 인구, 지역 내부 통근·통학 비중을 분석합니다.

**[🌐 지도 바로가기 - 통근·통학 이동 흐름 지도](https://tellgeniewish.github.io/Commute-Flow-Map/)**

통근·통학 통계는 KOSIS 인구총조사의 **12세 이상 인구**를 기준으로 합니다. 수집 데이터에는 전체(`T1`), 남자(`T2`), 여자(`T3`) 항목이 포함되어 있으며, 현재 웹 지도는 전체(`T1`)를 사용합니다.

## 🔍 분석 방법

1. **데이터 수집:** KOSIS OpenAPI를 이용하여 2020년 통근·통학 통계를 8개 권역별로 수집
2. **전처리:** 전체 인구(`T1`)를 선택하고 합계·기타·동일 시·도 이동을 구분하여 분석 대상 정리
3. **OD 분석:** 출발지와 도착지별 통근·통학 인구를 집계하고 권역 내 유입·유출 규모 산출
4. **이동 경로 생성:** 시·도별 대표 좌표를 이용하여 곡선형 이동 경로 생성
5. **통계 시각화:** 이동량 순위, 주요 이동 경로, 지역별 유입·유출 규모를 지도와 분석 패널에 표현
6. **단일 권역 분석:** 강원·전북·제주는 전체·관내 통근·통학 인구 및 확인 가능한 기타 지역 집계를 별도로 분석
7. **결과 도출:** 8개 권역의 이동 특성과 분석 범위를 비교하고 해석상 유의사항 제시

## 🎯 주요 기능

- **권역별 지도 탐색:** 전국 8개 권역을 선택하여 이동 현황 확인
- **OD 이동 흐름 시각화:** 출발지와 도착지를 연결하는 곡선 및 파티클 애니메이션 표시
- **이동량 순위 표현:** OD 이동량에 따라 5단계로 경로 구분
- **주요 이동 경로 분석:** 권역별 이동량 TOP 3와 이동 인구 확인
- **지역별 유입·유출 비교:** 시·도별 권역 내 유입·유출 인구 및 순유입 규모 비교
- **권역별 통계 요약:** 총 OD 이동량과 분석 경로 수를 통계 패널로 제공
- **단일 시·도 통계:** 강원·전북·제주의 전체·관내 통근·통학 인구와 구성비 표시
- **지도 상호작용:** 지역 호버 통계, 클릭을 통한 권역 전환, 지도 확대·축소 및 이동
- **데이터 갱신:** GitHub Actions를 통한 KOSIS 통계 수집 및 JSON 갱신

## 📚 데이터 출처 및 분석 방법

| 자료 | 활용 방법 | 비고 |
| --- | --- | --- |
| [KOSIS 국가통계포털](https://kosis.kr/) | 통근·통학 인구의 출발지·도착지 및 광역 단위 집계 활용 | 인구총조사, **2020년** |
| [KOSIS OpenAPI](https://kosis.kr/openapi/) | 권역별 통근·통학 통계 수집 및 JSON 생성 | 통계표 `DT_1PA2005`~`DT_1PA2012` |
| 전국 시·도 행정경계 GeoJSON | 지역 경계 표시, 권역 선택 및 지도 확대 범위 설정 | 원 공간자료의 출처·기준시점 확인 필요 |
| [OpenStreetMap](https://www.openstreetmap.org/) | 지도 배경 타일 | © OpenStreetMap contributors |

**OD(Origin–Destination)**는 출발지(Origin)와 도착지(Destination)의 관계를 의미합니다.

본 프로젝트에서는 KOSIS 통근·통학 통계의 현 거주지를 출발지, 통근·통학지를 도착지로 설정하여 시·도 간 이동 관계를 분석했습니다. 동일 시·도 내 이동은 다중 시·도 권역의 OD 화살표 분석에서 제외하며, 지역별 유입·유출은 권역에 포함된 서로 다른 시·도 간 이동만을 합산합니다.

시각화된 곡선은 지역 대표 좌표를 연결하는 것으로 실제 도로·철도 이동 경로를 의미하지 않습니다.

## 🚀 이용 및 실행 방법

별도의 프로그램 설치 없이 아래 링크로 접속하면 지도를 바로 이용할 수 있습니다.

**[🔗 통근·통학 이동 흐름 지도 바로가기](https://tellgeniewish.github.io/Commute-Flow-Map/)**

화면에서 8개 권역 중 하나를 선택하면 해당 지역의 통근·통학 이동 현황을 확인할 수 있습니다. 지도 위의 지역에 마우스를 올리면 통계 정보가 나타나며, 다른 지역을 클릭하면 해당 권역으로 전환됩니다.

다중 시·도 권역에서는 이동 경로 애니메이션과 통계 분석 패널을, 강원·전북·제주에서는 전체·관내 통근·통학 인구 중심의 통계 패널을 제공합니다.

<details>
<summary><strong>개발자용 로컬 실행 방법</strong></summary>

저장소를 복제한 뒤 VS Code의 Live Server 또는 로컬 HTTP 서버에서 실행합니다.

```bash
git clone https://github.com/tellgeniewish/Commute-Flow-Map.git
cd Commute-Flow-Map
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

JSON·GeoJSON 파일을 `fetch()`로 불러오므로 `index.html`을 직접 실행하기보다는 로컬 HTTP 서버를 사용하는 것이 적절합니다. Leaflet CDN과 OpenStreetMap 지도 타일을 표시하려면 인터넷 연결이 필요합니다.

KOSIS 데이터를 다시 수집하려면 GitHub 저장소의 **Actions → Fetch KOSIS data → Run workflow**를 실행합니다. 실행하려면 GitHub Secrets에 `KOSIS_API_KEY`가 설정되어 있어야 합니다.

</details>

## 📖 라이선스 및 이용 안내

소스코드와 데이터의 이용·재배포 조건은 저장소에 포함된 라이선스 파일과 각 원자료 제공기관의 이용약관을 확인해야 합니다. 별도의 오픈소스 라이선스가 명시되지 않았다면 자유로운 재배포가 허용된다고 가정하지 않습니다.

통계 자료를 인용할 때는 **KOSIS 인구총조사, 기준연도 2020년, 해당 통계표 ID**를 함께 표기하는 것을 권장합니다.

## ⚠️ 분석의 한계 및 유의사항

- **분석 범위:** 전국 17개 시·도를 포함하지만, 다중 시·도 권역에서는 해당 권역 내부의 서로 다른 시·도 간 이동만 시각화합니다. 권역 사이의 이동은 포함하지 않습니다.
- **집계 기준 차이:** 다중 시·도 권역의 OD 이동량과 강원·전북·제주의 전체·관내 통근·통학 인구는 산출 기준이 다릅니다.
- **단일 시·도 자료의 제약:** 강원·전북·제주는 구체적인 지역 간 이동 방향을 확인할 수 없어 임의의 OD 경로를 생성하지 않습니다.
- **제주 통계 해석:** 전체와 관내 통근·통학 인구가 동일하게 조회되지만, 외부 통근·통학 이동이 없다고 단정할 수 없습니다.
- **실제 이동 경로와의 차이:** 지도에 표시된 곡선은 통계상의 출발지·도착지 관계이며, 실제 도로·철도 노선 또는 개인의 이동 궤적이 아닙니다.
- **기준연도:** 2020년 인구총조사 자료이므로 현재 통근·통학 상황과 차이가 있을 수 있습니다.
- **성별 통계:** 데이터에는 남녀 구분 항목이 포함되어 있지만 현재 웹 시각화에서는 전체 인구(`T1`)만 사용합니다.
- **행정구역 명칭:** 통계 기준연도의 지명과 지도 행정경계의 명칭이 다를 수 있으므로 해석 시 주의가 필요합니다.
